Performed an authorized black-box penetration test on a simulated Ubuntu server following the NIST SP 800-115 methodology. The assessment included reconnaissance, scanning, enumeration, exploitation, and reporting phases to simulate a real-world attack scenario.

Discovered and documented 11 vulnerabilities, each evaluated using CVSS scoring and supported with clear remediation steps. Key issues included misconfigurations such as anonymous FTP access, weak permissions, and insecure cron jobs, which increased the system’s exposure to unauthorized access.

Used tools like Nmap for network scanning and service detection, LinPEAS for privilege escalation checks, and FTP/SSH for accessing and interacting with exposed services. Additional analysis techniques, including decoding encoded data, helped uncover sensitive information.

By chaining these vulnerabilities, successfully gained both user-level and root-level access. The project concluded with a structured report outlining findings, impact, and practical recommendations to improve system security.
