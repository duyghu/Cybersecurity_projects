Conducted an authorized phishing simulation to evaluate user awareness and email security controls. The campaign utilized a GoDaddy domain and Cloudflare Tunnel to host and deliver a realistic phishing scenario in a controlled environment.

Designed and deployed convincing phishing emails along with a simulated login portal using GoPhish, aiming to replicate real-world social engineering techniques. Monitored user interactions such as email opens, link clicks, and credential submissions to assess susceptibility and identify potential weaknesses.

The exercise concluded with a summary of findings and actionable recommendations, including improving security awareness training, strengthening email filtering mechanisms, and implementing additional safeguards to reduce phishing risks.
